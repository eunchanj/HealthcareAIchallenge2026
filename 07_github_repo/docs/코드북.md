# 코드북: 뇌 위축 바이오마커 예측과 MRI 검사 대상 선별 분석 파이프라인

Healthcare AI Challenge 2026 (국립보건연구원, 한국생명정보학회 공동주관) 접수번호 HAI-0024. 연구 제목 "임상 및 유전체 데이터 기반 뇌 위축 바이오마커 예측과 MRI 검사 대상 선별". 이 문서는 팀원이 코드와 산출물을 읽고 검토하고 재현할 수 있도록 폴더 구조, 노트북별 입력과 출력, 변수 정의, 산출물 파일, 실행 절차, 보안 규칙을 정리한 것이다. 연구 설계와 근거는 `01_연구기획관련/연구기획_최종_뇌위축바이오마커_MRI선별.md`에, 분석 중 변경 사항은 그 문서의 11절에 있다. 작성일 2026-10-04.

## 1. 반드시 지킬 보안 규칙

1. 원자료(`02_Data`의 임상, 뇌영상, 유전체 파일)는 외부로 보내지 않는다. 외부 AI 서비스 업로드, 공개 저장소 게시, 동기화 폴더 보관, 이메일 첨부 모두 금지다(데이터 활용 서약). 지금 `02_Data`가 OneDrive 동기화 경로 아래에 있으므로 동기화 제외 폴더나 로컬 암호화 폴더로 옮겨야 한다.
2. 유전형 파일(PLINK bed)은 노트북 02, 04, 06이 로컬에서만 읽는다. 결과 파일에는 개인 수준 유전형이 들어 있지 않다. 단, `05_분석결과/derived/lead_dosage.csv`(178개 변이의 개인별 대립유전자 수)와 `base_analysis.csv` 등 파생 자료는 개인 수준 자료이므로 원자료와 같은 등급으로 다룬다.
3. TabPFN 키는 `code/.tabpfn_token`에만 두고 공유하거나 제출물에 넣지 않는다(`.gitignore`에 포함). 대회 종료 후 키는 ux.priorlabs.ai에서 폐기한다.
4. 산출물의 외부 공개와 논문 게재는 서약서상 금지 사항이므로 결과보고서 제출 외 용도로 쓰지 않는다. 자료는 대회 종료일에 삭제한다.
5. 평가군 2,000명은 2026-09-28에 한 번 평가했다(노트북 05, `DRY_RUN = False`). 이 실행은 다시 하지 않으며, 주 모델과 기준도 바꾸지 않는다. 그 뒤의 모든 탐색은 개발군 8,000명 안에서만 한다(노트북 07).

## 3. 실행 환경

Python 3.10 이상. 주요 패키지와 확인된 버전: numpy 2.2, pandas 2.3, scipy 1.15, statsmodels 0.15, scikit-learn 1.7, lightgbm 4.7, xgboost 3.2, catboost 1.2, matplotlib 3.10, nbformat 5.11, tabpfn 9.0.0(torch 2.9 포함). 그림의 한글 글꼴은 AppleGothic, Malgun Gothic, NanumGothic, Noto Sans CJK 중 설치된 것을 자동으로 쓴다.

TabPFN-3.5는 연구 및 평가용 라이선스다. ux.priorlabs.ai에서 계정을 만들고 Licenses 탭에서 TabPFN-3.5 라이선스에 동의한 뒤 API 키를 `code/.tabpfn_token`에 저장한다. 라이선스 동의는 모델 버전마다 따로 필요하고, 패키지 9.0.0 미만에는 3.5 모델이 없다. 가중치는 처음 한 번 내려받아 로컬 캐시에서 읽으며, 원자료가 외부로 나가는 클라우드 API(`tabpfn-client`)는 쓰지 않는다.

맥에서는 torch와 LightGBM, XGBoost, CatBoost가 각자 OpenMP 런타임을 가지고 있어 한 커널에서 함께 계산하면 커널이 죽는다. 그래서 TabPFN 계산은 항상 별도 프로세스(`code/tabpfn_worker.py`)에서 하고, 노트북 커널은 결과 파일만 읽는다. 공용 모듈은 실제로 계산하는 모델의 라이브러리만 불러오도록 되어 있다.

## 6. 공용 모듈 (`code/`)

**`tabular_model_comparison.py`** 모델 비교 파이프라인. `Config`(task, outer_folds 5, repeats 2, inner_folds 3, n_iter 40, seed 20260915, n_boot 1000, models, selection_tol 0.01, tabpfn_n_estimators 8, tabpfn_version "v3.5", tabpfn_device "auto")와 `run(df, id_col, target, features, cat_cols, group_col, cfg, out_dir, resume, compute_only)`이 핵심이다. 외부 K분할을 R회 반복해 OOF 예측을 만들고, 내부 교차검증 무작위 탐색으로 모델당 같은 횟수만큼 튜닝한다. 전처리는 선형, SVM, TabPFN은 중앙값 대치와 결측 지시자와 표준화, 트리와 GBDT는 결측을 그대로 둔다. 지표는 AUROC, AUPRC(사전 지정 선택 기준), Brier, 보정 기울기와 절편, 배정률 10, 20, 30%의 민감도와 PPV와 1명 발견당 MRI 건수다. 선택 규칙은 AUPRC 최고 모델, 최고와 0.01 이내면 더 단순한 모델(단순성 순서 enet, tabpfn, rf, lgbm과 xgb와 cat, svm), 같은 단순성이면 보정 기울기가 1에 가까운 모델이다. `compute_only`는 재사용하지 못한 모델 중 계산할 것을 제한한다(TabPFN 작업자용). 회귀(task "regression")도 지원하며 지표는 MAE, RMSE, R²다.

**`block_increment.py`** `models/full_*`의 OOF 예측으로 블록 간 쌍체 부트스트랩(2,000회)을 계산해 `table2_model_comparison_dev.csv`와 `table3_block_increment.csv`를 만든다. 노트북 03 마지막에 자동 실행된다.

**`tabpfn_worker.py`** TabPFN을 별도 프로세스에서 실행한다. `check`(합성 난수로 라이선스, 가중치, 장치, 속도 단계별 점검), `run`(한 블록의 TabPFN OOF만 계산해 기존 결과에 합침; 과제, 목표 변수, 앙상블 수 지정 가능), `final`(노트북 05용: 개발군 전체 적합, 5분할 교차예측, 평가군과 추적군 예측 저장).

**`worker_util.py`** 노트북에서 작업자를 실행하고 출력을 실시간으로 보여 주며, 종료 코드로 실패 원인(OpenMP 충돌, 라이선스, 가중치 내려받기, 메모리 부족 등)을 설명한다.

## 7. 변수 사전

### 7.1 특수코드와 조화 규칙 (노트북 01)

원자료의 66666과 99999는 결측으로, 77777(해당 없음)은 양, 빈도, 기간 변수(음주량, 흡연량과 기간, 갑년, 총 음주량)에서는 0으로, 그 밖에는 결측으로 처리한다. 예와 아니오는 1이 아니오, 2가 예이므로 0과 1로 바꾼다. 흡연은 SMOKE 2를 과거, 3을 현재로, 음주도 같은 방식으로 지시변수를 만든다. 가족력은 부모 중 한 명이라도 있으면 1이다. 추적군의 갑년은 하루 개비 ÷ 20 × 흡연 기간이고, LDL이 없을 때는 Friedewald 식(TG < 400)으로 계산한다.

| `atrophy_pos_b20`, `wb_pos`, `vent_pos`, `composite_pos` | 민감도와 보조 결과: 개발군 하위 20%, 전체 뇌 z ≤ −1, 뇌실 z ≥ +1, 해마 또는 전체 뇌 위축 |

### 7.3 결과변수 정의 (노트북 01)

개발군 8,000명에서 `hip_ratio ~ cr(age, df = 4) + male`(자연 3차 스플라인 OLS)을 적합해 기대치 곡선을 고정하고, z = (관측 − 기대치) ÷ 잔차 SD(개발군)로 정의한다. 평가군, 추적기반, 4차추적 모두 이 고정 곡선을 쓴다(4차추적은 4차 시점 연령으로 기대치 계산). 해마 비율의 기대치 R²는 0.313, 잔차 SD는 0.000587이다. 전체 뇌와 뇌실도 같은 방식이다.

### 7.4 추적군 파일

`follow_baseline.csv`(추적기반 1,000명)는 7.2와 같은 임상 변수, `edu`, `edate`(검진 연월), 뇌 체적과 z, `atrophy_pos`를 담는다. `follow_longitudinal.csv`(4차추적 698명)는 거기에 `age5`, `edate5`, `*_5`(4차 체적, 비율, z), `years`(추적 기간, 평균 10.8년), `spc_hip`과 `rate_hip`(대칭 백분율 변화와 연간 변화율, 전체 뇌와 뇌실도 같음), `accel_atrophy`(연간 변화율 하위 20%), `icv_change_pct`를 더한 것이다. 추적군은 기반군과 다른 사람들이며 유전체가 없다.

## 8. 모델 비교 프로토콜과 확정된 주 모델

개발군 8,000명 안에서 외부 5분할 × 2회 반복(시드 20260915, 20260916)의 OOF 예측으로 성능을 구하고, 각 외부 훈련 폴드 안에서 내부 3분할 무작위 탐색 40회로 튜닝한다. 모델은 Elastic-net 로지스틱, Random Forest, LightGBM, XGBoost, CatBoost, TabPFN-3.5(앙상블 8, 튜닝 없음)다. 전체 모델 비교는 M1, M1+G, M1−Dx, M1−Dx+G에서 하고, M1+G의 AUPRC 상위 2개(XGBoost, CatBoost)만 나머지 블록에 적용했다.

확정 주 모델(2026-09-28): M0 CatBoost, M1 Elastic-net, M2 CatBoost, G CatBoost, M1+G Elastic-net, M2+G CatBoost, M1−Dx Elastic-net, M1−Dx+G TabPFN-3.5. 평가군 평가 전에 각 주 모델을 개발군 전체로 같은 예산으로 다시 튜닝하고, 최종 초모수로 만든 개발군 5분할 교차예측에 로지스틱 재보정(Platt)을 적합해 적용했다(`final_models/*.pkl`, `table_final_models.csv`).

## 10. 재현 절차

1. `02_Data`에 원자료를 두고, `code/.tabpfn_token`에 키를 넣는다(TabPFN을 쓰지 않으려면 노트북 03의 `USE_TABPFN = False`).
2. 노트북 01 → 02 → 04 → 03 → 05 → 06 → 07 순서로 실행한다. 03은 `FAST = True`로 한 번 동작을 확인한 뒤 `FAST = False`로 정식 실행하고, 05는 `DRY_RUN = True`로 점검한 뒤 `DRY_RUN = False`를 한 번만 실행한다(이미 실행된 정식 결과가 있으면 다시 하지 않는다).
3. 시드는 모두 20260915로 고정되어 있어 같은 환경에서는 같은 결과가 나온다. TabPFN은 장치(CPU 또는 애플 GPU)에 따라 소수점 아래에서 미세하게 다를 수 있다.
4. 결과보고서 수치는 `tables/`의 접두어 없는 csv에서 가져온다. `05_분석결과/결과요약_평가군_종단검증_20260928.md`에 평가군 결과 요약이 있다.

## 11. 검토를 부탁하는 지점

**유전체 검토** 노트북 04의 APOE 정의(합성 bim의 대립유전자 문자가 임의여서 소수 대립유전자 기준으로 정의한 것이 타당한지), lead 변이의 문헌 형질군 배정표(`LIT` 사전)의 오류 여부, 희소 PRS를 개발군 질환 자료로 적합한 방식의 적절성, 노트북 06 MR의 도구변수 가정(특히 측정치를 노출로 둔 2SLS에서 배제 제한이 깨지는 해석)과 1-표본 설계의 약한 도구 편향 서술.

**통계 검토** 노트북 05의 재보정 절차(최종 초모수 교차예측 기반 Platt)와 평가군 부트스트랩, Holm 가족 구성(주 검정 4건), 종단 검증에서 평균 회귀 구조에 대한 해석과 보조 분석 처리, 노트북 06 자연효과 분해에서 총효과 = NIE + NDE 정의와 선형 주변 기울기의 차이, 노트북 07의 사후 탐색 규칙(평가군 2차 사용 조건)이 충분히 보수적인지.

**임상 검토** 입력 블록 구성(검진 문진 수준 M1과 혈액검사 M2의 구분), MRI 배정률 시나리오(10, 20, 30%)와 위험 3구간의 현장 적용 가능성, 선별 음성으로 임상적으로 필요한 MRI를 보류하지 않는다는 원칙의 문구.
