# 임상 및 유전체 데이터 기반 뇌 위축 바이오마커 예측과 MRI 검사 대상 선별

부제: 예측모형 개발 및 뇌 위축의 유전적 연관성 분석
영문: Clinical and genomic data-based prediction of brain atrophy biomarkers for selecting MRI screening candidates

KNIH–KSBi Joint Healthcare AI Challenge 2026 | 연구기획 최종본 (9/22 분석 중 변경 반영) | 2026-09-22 | 접수번호 HAI-0024

> **골자** 입력 = 임상역학 정보 + 유전체 변수(APOE, PRS) / 결과 = 뇌 위축(MRI로만 확인되는 바이오마커) / 분석 1 = 예측모델(표형 데이터 강점 모델 다중 비교) / 분석 2 = 유전체 기반 뇌 위축 연관 및 기전 분석 / 활용 = MRI 검사 대상 선별

## 2. 연구 개념

뇌 위축(해마 위축, 전체 뇌 위축, 뇌실 확대)은 신경퇴행의 대표 바이오마커이지만 MRI를 찍어야만 알 수 있다. [1] 본 연구는 **MRI 없이 얻을 수 있는 기본 임상 변수와 유전체 정보만으로 이 MRI 바이오마커를 얼마나 추정할 수 있는지**를 검증하고, 추정 점수를 **뇌 MRI 검사 대상 선별의 우선순위**로 쓰는 방안을 제시한다. 세 자료의 역할은 다음과 같다.

```
임상역학(약 60변수) + 유전체(APOE, PRS, PC)  ──▶  [분석 1] 뇌 위축 예측모델  ──▶  Pre-MRI 위축 위험점수 ──▶  MRI 검사 대상 선별
                       유전체 ────────────────▶  [분석 2] 유전체–뇌 위축 연관 스캔, 경로(MR) 분석 ──▶  기전 해석, PRS 근거
뇌 MRI 66 ROI(기반 1회, 추적 2시점 +10.8년) ──▶  결과(정답) 정의: 단면 위축 표현형(주) + 종단 위축 속도(검증)
```

**핵심 질문** ① 임상 및 유전체 정보로 위축 표현형을 어느 정도 판별하는가 ② 유전체는 임상 정보에 무엇을 더하는가 ③ 어떤 유전 요인이 위축과 연관되며 대사질환을 거쳐 작용하는가 ④ 같은 MRI 건수로 위축자를 얼마나 더 찾는가.

### 3.2 결과변수 정의

뇌 위축 결과변수는 두 층위로 정의한다. 단면 정의는 "같은 연령과 성별의 기대치보다 얼마나 작은가"를, 종단 정의는 "같은 사람의 과거보다 얼마나 줄었는가"를 재며, 둘 다 해마를 주 영역으로 한다.

**표 2 뇌 위축 표현형(결과) 정의**

| 구분 | 정의 | 용도 |
| --- | --- | --- |
| **주 결과(단면)** 해마 위축 | 해마 비율(BV_subctx_hippocampus / BV_icv)의 연령 및 성별 기대치 대비 잔차 z-점수; **z ≤ −1 → 위축 양성** | 분석 1 주 결과, 분석 2 주 표현형 |
| 보조(단면) | 전체 뇌 비율 z ≤ −1, 뇌실 비율 z ≥ +1, 복합(둘 중 하나 이상) — 같은 방식으로 산출 | 보조 결과 |
| 연속 결과(단면) | 해마, 전체 뇌, 뇌실의 z-점수 | 회귀, 연관 스캔, PRS 연관 |
| **종단 검증(주)** 4차추적 위축 상태 | 기반군에서 고정한 기대치 곡선을 4차추적 연령에 적용한 해마 z(4차) ≤ −1; 함께 추적 안정성(기저 z와 4차 z의 상관, 기저 양성의 4차 유지율) | 기저 임상 점수가 10.8년 뒤 MRI 위축 상태를 예측하는지 |
| 종단 검증(보조) 가속 위축 | 두 시점 해마 체적 연간 변화율; 추적군 안에서 하위 20% = 가속 위축 | 평균 회귀 한계를 명시한 보조 분석 |

**단면 정의의 산출 절차**

1. 정규화: 해마 비율 = 해마 체적 / ICV. 머리 크기에 따른 개인차를 제거한다.
2. 기대치 곡선: 기반군 개발군(80%, 약 8,000명) 전원에서 해마 비율을 결과로, 연령의 자연 3차 스플라인(매듭 3–4개)과 성별을 설명변수로 하는 회귀식을 적합한다. 어떤 사람의 연령과 성별을 이 식에 넣어 얻는 예측값이 그 사람의 "기대치"이며, 곧 이 자료 안에서 같은 연령과 성별인 사람들의 평균 해마 비율이다.
3. z-점수: z = (관측 해마 비율 − 기대치) / SD, SD는 개발군 잔차의 표준편차다.
4. 경계: z ≤ −1을 위축 양성으로 한다(정규 가정 시 약 16%). 기대치 곡선의 계수, 잔차 SD, 경계값은 개발군에서 한 번 추정해 고정하고, 평가군 2,000명과 추적기반 1,000명(T01_AGE, T00_SEX 사용)에는 적용만 한다.

```
해마 비율 = BV_subctx_hippocampus / BV_icv
기대치(연령, 성별) = β0 + f(연령; 자연 3차 스플라인) + β1 × 성별      (개발군 전원에서 적합)
z = (해마 비율 − 기대치) / SD(개발군 잔차)
위축 양성 = z ≤ −1
```

**단면 정의의 선택과 근거** 기대치는 외부의 한국인 정상치가 아니라 본 자료에서 추정한다. 합성 자료의 절대 크기가 실제 측정값과 다를 수 있고, 평가군과 추적군에 같은 식을 적용해야 일관성이 유지되기 때문이다. 기대치의 기준 집단은 개발군 전원으로 한다. 대사질환이 없는 사람만으로 기준을 잡으면 "건강한 사람 대비 위축"이라는 뜻은 분명해지지만, 질환 진단 여부가 결과변수 정의와 예측모델 입력에 동시에 들어가 순환이 생기므로 이는 민감도 분석으로 둔다. 성별은 하나의 식에 공변량으로 넣되, 점검 단계에서 성별×연령 상호작용이 확인되면 성별 분리 적합으로 사전 변경한다. 잔차 SD는 단일값을 기본으로 하고, 연령에 따라 산포가 커지면 연령대별 SD 또는 GAMLSS 방식(성장곡선의 백분위 방식)으로 바꾼다. 그 밖의 민감도 분석은 ICV를 비율 대신 공변량으로 넣는 잔차 보정 방식과 하위 20% 경계다. 이 모든 선택은 평가 결과를 보기 전에 고정한다.

**종단 정의의 산출 절차** 주 결과는 수준이다. 기반군 개발군에서 고정한 기대치 곡선에 4차추적 시점의 연령(T05_AGE)과 성별을 넣어 4차추적 해마 비율의 z를 구하고, z ≤ −1을 4차추적 위축 양성으로 한다. 추적 안정성은 기저(추적기반) z와 4차 z의 상관, 그리고 기저 위축 양성군과 음성군 각각에서 4차에 양성인 비율로 나타낸다. 보조 결과는 같은 사람의 추적기반 해마 체적 V1과 4차추적 해마 체적 V5의 변화율이다(한 사람 안에서 머리 크기는 변하지 않으므로 원 체적을 그대로 쓴다).

```
4차추적 위축 양성 = z(4차) ≤ −1,  z(4차) = (해마 비율(4차) − 기대치(연령 4차, 성별)) / SD(개발군 잔차)
대칭 백분율 변화 = (V5 − V1) / ((V5 + V1) / 2) × 100
경과연수 Δt = (T05_EDATE − T01_EDATE) / 12      (YYYYMM 기준 개월 수)
연간 변화율(%/년) = 대칭 백분율 변화 / Δt        (해마는 음수가 감소)
가속 위축(보조) = 추적군 698명 안에서 연간 변화율 하위 20%
```

변화율을 보조로 두는 이유는 수령 자료 점검(9/22)에서 확인된 구조 때문이다. 추적 자료는 기저에 해마가 작을수록 이후 감소가 느리고(기저 z와 변화율의 상관 −0.36), 고혈압군과 당뇨군의 해마가 비질환군보다 느리게 줄어드는 평균 회귀 구조를 보여, 변화율을 결과로 쓰면 "질환이 있으면 덜 위축된다"는 생물학적으로 타당하지 않은 결론이 나온다. 반면 단면 z는 10.8년 뒤에도 유지되고(상관 0.83) 기저 양성군의 4차 양성률이 음성군보다 훨씬 높아, 수준을 결과로 쓰는 것이 자료의 구조에 맞는다. 변화율 분석은 기저 해마 체적, 연령, 성별, ICV를 보정한 회귀로 보고하되 이 한계를 함께 적는다.

**두 정의의 연결** 기반군에서 고정한 기대치 곡선을 추적기반과 4차추적 두 시점에 적용하면 같은 사람의 단면 z가 두 번 나온다. 기저 위축 양성군이 10.8년 뒤에도 양성으로 남는 비율과 음성군에서 새로 양성이 되는 비율을 비교해, 한 시점의 작은 해마가 일시적 편차가 아니라 지속되는 상태인지 확인한다(그림 5).

**용어의 근거** 한 시점의 MRI에서 연령 기대치보다 작은 해마 체적을 "위축"으로 부르는 것은 임상 영상판독의 시각적 위축 척도(MTA)와 NIA-AA 연구 틀의 신경퇴행(N) 바이오마커가 모두 단면 MRI 지표라는 점에 근거한다. [1] 다만 한 시점의 작은 체적에는 초기 생애 요인이 섞일 수 있으므로 위의 연결 분석으로 두 의미 사이의 간극을 실증적으로 닫는다. 인지나 치매 변수는 없으므로 치매 예측은 주장하지 않는다.

| C0 기본 | 연령, 성별 | 최소 기준 |
| C1 임상 기본 | 혈압, BMI 및 허리둘레, 흡연(갑년 T_PACKYR 포함), 음주(총 음주량 T_TOTALC 포함), 운동, 고혈압, 당뇨, 고지혈증 진단력, 부모의 고혈압 및 당뇨 가족력. 기반군에는 교육수준이 없고 소득(T_INCOME)은 있음; 추적군에는 교육수준이 있고 소득이 없음 → 둘 다 종단 이전 변수에서 제외 | 채혈과 MRI 없이 산출 |
| C2 검진 혈액 | 혈당, HbA1c, 총콜레스테롤, HDL, LDL, TG, AST/ALT, 크레아티닌 | 추적군에 LDL 없음(인슐린은 추적군에만 있음) → 종단 이전 시 LDL은 Friedewald로 산출하고 인슐린은 제외 |
| G 유전체 | APOE ε4 보유 수(rs429358, rs7412); lead 변이 178개를 형질군(제2형 당뇨, 혈압, 지질, 비만, 음주 대사, APOE 및 AD 관련, 뇌 관련 등)으로 분류한 **희소 PRS**; 유전적 PC 1–10 | 가중치는 외부 GWAS 효과 크기 [7–9] 또는 훈련 분할 내 추정(두 방식 모두 보고) |

수령한 유전체는 실제 rsID를 가진 lead 변이가 178개뿐이고 나머지는 합성 ID의 LD 이웃과 배경 null SNP이므로, 외부 요약통계와 대조되는 전장 PRS(PRS-CS, C+T)는 성립하지 않는다. 따라서 **lead 변이 기반 희소 PRS를 유일한 방법**으로 하고 [10], lead 변이의 형질군 분류는 GWAS Catalog와 원 논문으로 확인해 사전 고정한다. APOE는 두 변이의 대립유전자 방향을 확인한 뒤 ε4 보유 수를 산출한다.

## 4. 분석 1 — 뇌 위축 예측모델

**분할** 추적군 1,000명은 독립 종단 검증군으로 분리한다. 기반군은 연령대, 성별, 질환을 층화해 80% 개발군과 20% 평가군으로 나누고, 근연 집단은 같은 분할에 둔다. 개발군 안에서 5분할 중첩 교차검증으로 전처리, PRS 선택, 튜닝 및 확률 보정을 모두 훈련 분할 안에서 수행하고 시드와 분할을 사전 고정한다.

### 4.1 표형 데이터 모델 비교 설계

표본이 수천 명, 변수가 60–100개인 전형적 표형(tabular) 데이터이므로, 최근 벤치마크(TabArena 2025–2026)에서 이 규모에 강한 것으로 확인된 모델군을 **같은 분할, 같은 전처리, 같은 튜닝 예산**에서 비교한다. [13–17] 딥러닝은 이 규모에서 GBDT를 넘기 어렵다는 근거가 누적되어 있어 [14, 15] 처음부터 학습하는 신경망은 2군으로 두고, 대신 소규모 데이터에서 GBDT를 앞서는 표형 파운데이션 모델(TabPFN 계열)을 1군에 포함한다. [16, 17]

**표 4-1 비교 모델군**

| 군 | 모델 | 포함 이유 | 튜닝 |
| --- | --- | --- | --- |
| 1군(필수) | Elastic-net 로지스틱/선형 회귀 | 해석 가능한 기준선, 계수 보고 | α, l1_ratio |
| 1군 | Random Forest | 설명회 추천 모델, 안정적 비교 기준 | 트리 수, 깊이, 특징 수 |
| 1군 | LightGBM | GBDT 중 TabArena 최상위, CPU에서 빠름 | 잎 수, 학습률, 정규화, 서브샘플 |
| 1군 | XGBoost | 설명회 추천, 심사위원에게 익숙 | 깊이, 학습률, 정규화 |
| 1군 | CatBoost | 범주형 처리와 기본값 성능, 보정 우수 | 깊이, 학습률, l2 |
| 1군 | TabPFN-3.5 (tabpfn 9.0 이상, 연구 및 평가용 라이선스, 로컬 추론) | 1만 명 이하 표본에서 단일 순전파로 튜닝된 GBDT를 앞섬 [16, 17]; 튜닝 불필요 | 없음(앙상블 수 8, 패키지 기본값) |
| 2군(시간 허용 시) | RealMLP 또는 TabM | 처음부터 학습하는 신경망 대표 [15] | 학습률, 폭, 드롭아웃 |
| 2군 | SVM(RBF) | 설명회 추천 | C, γ |
| 2군 | 스태킹 앙상블 | 1군 OOF 예측을 로지스틱 메타학습기로 결합 | 없음 |
| 참고 | AutoGluon (best_quality) | 자동 앙상블 상한선 참고치; 주 결과로 쓰지 않음 | 시간 예산 |

**비교 프로토콜**

1. 분할: 개발군 안에서 대상자 단위 5분할 외부 교차검증을 2회 반복(시드 고정)하고, 외부 폴드별 OOF 예측을 모아 성능을 산출한다. 튜닝은 각 외부 훈련 폴드 안의 내부 3분할 교차검증에서 무작위 탐색을 **모델당 동일 횟수(예: 40회)** 로 수행해 예산을 맞춘다.
2. 전처리: 트리와 GBDT는 결측을 원자료 그대로(내장 처리), 선형, SVM, 신경망, TabPFN은 중앙값 대치 + 결측 지시자 + 표준화. 전처리 적합은 훈련 폴드 안에서만 한다.
3. 지표: 분류 — AUROC(주 보고), AUPRC(사전 지정 선택 기준), Brier, 보정 절편과 기울기, 배정률 20% 민감도. 회귀(종단 속도) — MAE, RMSE, R². 모델 간 차이는 같은 대상자의 쌍체 부트스트랩 1,000회로 95% 신뢰구간을 구한다.
4. 선택 규칙(사전 고정): 개발 교차검증 AUPRC 최고 모델을 주 모델로 하되, 최고와의 차이가 0.01 이내면 더 단순하고 보정이 좋은 모델을 택한다. 주 모델은 평가군에서 **한 번만** 평가한다. 나머지 모델의 평가군 성능도 투명성을 위해 보고하되 주 모델을 사후에 바꾸지 않는다.
5. 범위 통제: 전체 모델 비교는 주 비교 블록(M1, M1+G)에서 수행하고, 선택된 상위 2개 알고리즘만 M0부터 M2+G까지 전 블록에 적용한다.
6. 해석: GBDT는 SHAP, 선형은 계수, TabPFN은 순열 중요도를 쓴다. 변수 의존성 설명용이며 인과 해석은 하지 않는다.

**평가** 평가군에서 AUROC 및 AUPRC, Brier, 보정 절편과 기울기를 제시하고, 모델 간 쌍체 ΔAUROC와 배정률 20%에서의 민감도 차이를 대상자 단위 부트스트랩 2,000회 95% 신뢰구간으로 제시한다(9/28 변경). 확률은 최종 초모수로 만든 개발군 교차예측에 적합한 로지스틱 재보정을 적용해 제시한다. **종단 검증**: 추적군에는 유전체가 없으므로 기반군에서 학습한 임상 모델(M1, M2)을 추적기반 시점 정보에 적용해 점수를 산출한다. 주 결과는 (i) 이 점수가 4차추적 시점의 위축 양성을 판별하는지(AUROC, 부트스트랩 신뢰구간) (ii) 추적 안정성(기저 z와 4차 z의 상관, 기저 양성군과 음성군의 4차 양성률)이다. 점수에 기저 z를 더한 모형은 영상이 있는 상황의 참고 기준으로만 제시한다. 보조 결과는 가속 위축 판별(AUROC)과 연간 변화율 회귀(기저 해마 체적, 연령, 성별, ICV 보정)이며 평균 회귀 한계를 함께 보고한다. 4차추적 시점 값은 입력에 쓰지 않으며, 탈락(1,000명 중 302명)은 기저 특성 비교와 관측확률 가중으로 점검한다.

### 4.2 성능 개선을 위한 방법론 연구 (사후 탐색, 개발군 전용; 10/4 추가)

분석 1의 주 결과(평가군 1회 평가, 9/28)는 고정한다. 그 뒤에 "같은 자료에서 더 끌어낼 수 있는 신호가 있는가"를 묻는 방법론 연구를 **개발군 8,000명 안에서만** 수행하고, 결과는 사후 탐색으로 표시해 보고한다. 가설과 판정 규칙은 실행 전에 아래와 같이 고정했다.

| 번호 | 가설 | 방법 | 비교 대상 |
| --- | --- | --- | --- |
| H1 | 결과를 이분화하지 않고 연속 해마 z를 회귀한 뒤 순위를 쓰면 판별력이 오른다 | Elastic-net 회귀와 CatBoost 회귀로 z_hip 예측, 예측값 순위로 위축 양성 AUROC와 AUPRC 산출 | M1 Elastic-net 분류 |
| H2 | 기존 블록에 없는 임상 변수(질환 이환 기간 = 나이 − 진단 나이, 맥박, 엉덩이둘레, 신장, 체중, 간접흡연, 결혼 상태, 소득, 검진 연도, 폐경 여부)가 신호를 더한다 | 확장 블록 M1+에 Elastic-net과 CatBoost 적용(77777은 해당 없음 0 또는 결측 지시자) | M1 |
| H3 | 모델 결합이 단일 모델보다 낫다 | 6개 모델의 OOF 예측을 로지스틱 메타학습기로 결합(중첩 교차검증) | M1 최고 단일 모델 |
| H4 | TabPFN 설정 변경이 도움이 된다 | 앙상블 수 8 → 32, TabPFN 회귀(H1과 결합) | TabPFN-3.5 기본 |
| H5 | 세 뇌 체적 z의 공통 요인을 보조 목표로 쓰면 잡음이 줄어든다 | z_hip, z_wb, z_vent의 첫 주성분을 회귀한 뒤 위축 양성 순위에 사용 | H1 |
| H6 | (해석용) 성능 상한은 자료가 정한다 | 학습 곡선(n = 1,000 ~ 8,000)에서 M1 AUROC의 평탄화 확인 | 없음 |
| H7 | (보조) 결과 정의를 바꿔도 모델 순위가 유지된다 | z ≤ −1, 하위 20%, 복합 위축에서 블록별 모델 순위 비교 | 없음 |

**규칙** (1) 모든 가설은 분석 1과 같은 중첩 교차검증(외부 5분할 × 2회, 내부 3분할, 탐색 40회)과 같은 분할 시드로 평가하고, 같은 대상자의 쌍체 부트스트랩으로 M1 Elastic-net 대비 차이와 신뢰구간을 구한다. (2) H1부터 H5까지의 주 비교 5건에 Holm 보정을 적용한다. (3) **평가군 2차 사용 조건**: 개발군에서 ΔAUPRC ≥ 0.01이고 Holm 보정 p < 0.05인 가설이 있을 때만, 그중 가장 단순한 하나를 평가군에서 한 번 더 평가하고 "사후 탐색의 확인 검정(평가군 2차 사용)"으로 표시해 보조 결과로 보고한다. 조건을 만족하는 가설이 없으면 평가군은 다시 쓰지 않는다. (4) 어느 경우에도 9/28 주 결과와 주 모델은 바꾸지 않는다.

## 6. MRI 검사 대상 선별 활용

평가군의 10, 20, 30%만 MRI를 받을 수 있다고 가정하고 무작위, 연령순, M1, M1+G, M2+G 순위를 같은 건수에서 비교한다.

```
민감도(발견률) = TP / N_위축양성      PPV = TP / N_배정      위축자 1명 발견당 MRI 건수 = 1 / PPV
```

산출물은 배정률별 발견률, 놓치는 수, 1명당 MRI 건수, 그리고 위험 3구간(저, 중, 고)별 위축 유병률이다. 진단력 미확보 시나리오(M1−Dx 대 M1−Dx+G)에서는 진단 이력이 없는 사람에게 유전체가 검사 우선순위를 얼마나 회복시키는지를 같은 지표로 제시한다. 유전체 보유자와 비보유자 시나리오를 나눠 제시하고, 검사 건수 감소만으로 비용 절감이나 예후 개선을 주장하지 않으며, 선별 음성으로 임상적으로 필요한 MRI를 보류하는 규칙은 제안하지 않는다.

## 7. 통계 원칙과 위험

평가 결과를 보기 전에 결과 정의(z 경계), 입력 블록, PRS 목록, 모델 선택 규칙, 배정률을 고정한다. 주 비교는 M1+G 대 M1, M1−Dx+G 대 M1−Dx, 종단 검증 2건(4차추적 위축 상태 AUROC, 추적 안정성)으로 한정하고 Holm 보정을 적용하며, 그 외는 탐색으로 표시한다. 전장 스캔은 5×10⁻⁸ 기준선을 참고로 표시하되 실질 검정은 lead 변이와 LD 이웃 2,116개에 Bonferroni를 적용한다.

**표 6 주요 위험**

| 위험 | 대응 |
| --- | --- |
| 합성 MRI가 연령, 성별, 질환 규칙으로 생성 → 예측이 규칙 재현일 수 있음 | M0와 질환 단순 기준을 나란히 제시; 질환 보정 후 z로 민감도 분석 |

| 유전체 구조가 lead 178개 + null 배경으로 단순함 | 전장 PRS와 유전자 기반 분석은 하지 않고 lead 변이 기반 희소 PRS와 형질군별 연관으로 한정; 방법의 한계로 명시 |

| 종단 자료가 두 시점뿐 | 변화율 회귀로 검증하고 궤적 모델링은 하지 않음 |

| 임상 정보의 판별 상한이 낮음(점검 ②에서 AUROC 약 0.63) | 상한을 정직하게 제시하고 자원 효율(같은 MRI 건수의 발견률)로 활용 가치를 보임; 유전체는 진단력 대체 시나리오로 가치를 평가 |
| 해석 경계 | 위축 양성은 확정 질환이 아님; 실제 코호트 재검증 필요 |

## 10. 결과보고서 표지용 문안(안)

**모델명** Pre-MRI 위축 위험점수 (G-BAS)

**주요 활용 데이터** KoGES 기반조사 교육용 임상역학 자료(10,000명)와 추적조사 자료(1,000명, 4차추적 698명), 뇌 MRI 체적 합성데이터(66개 ROI, 기반 10,000명과 추적 2시점), K-CHIP 유전체 합성데이터(기반 10,000명, 상염색체 100만 SNP)

**연구요약** 뇌 위축은 신경퇴행의 핵심 바이오마커이지만 MRI를 촬영해야만 확인할 수 있다. 본 연구는 기본 임상 변수와 유전체 정보(APOE, 다유전자 위험점수)만으로 MRI 뇌 위축 바이오마커를 예측하는 모델을 개발하고, 이를 MRI 검사 대상 선별 도구로 활용하는 방안을 검증한다. 기반 코호트 10,000명에서 연령 및 성별 보정 해마 체적 z-점수로 위축 표현형을 정의하고, 임상 정보와 유전체 정보를 단계적으로 결합한 모델을 표형 데이터에 강한 여러 알고리즘으로 같은 조건에서 비교해 판별력과 유전체의 추가 가치를 독립 평가군에서 검증한다. 추적 코호트에서는 기저 임상 정보로 산출한 점수가 10.8년 뒤 MRI 위축 상태를 예측하는지와 위축 표현형이 시간이 지나도 유지되는지 확인한다. 아울러 유전체 자료에 포함된 만성질환 관련 변이의 희소 다유전자 점수와 APOE의 연관 분석, 매개분석과 멘델리안 무작위화로 유전 요인이 대사질환을 거쳐 뇌 위축에 이르는 경로를 분석한다. 최종 산출물은 MRI 배정률별 위축자 발견률과 1명 발견당 검사 건수로 제시하는 Pre-MRI 위축 위험점수다.

**기대효과** 검진이나 1차의료처럼 MRI 접근이 제한된 상황에서 이미 확보된 임상 정보와 유전체 정보로 뇌 위축 가능성이 높은 사람을 먼저 찾아 검사 자원을 효율적으로 배정하는 근거를 제공한다. 같은 검사 건수에서 발견률이 얼마나 오르고 누락이 얼마나 남는지를 함께 제시해 실제 적용 조건을 명확히 하며, 임상, 영상, 유전체 세 자료의 역할을 분리한 분석 틀은 합성 코호트 자료의 신호 보존 여부를 점검하는 방법론으로도 활용될 수 있다.
