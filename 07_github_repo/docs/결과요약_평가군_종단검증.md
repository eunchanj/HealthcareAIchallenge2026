# 결과 요약: 평가군 고정 평가와 종단 검증 (9/28)

노트북 03(개발군 교차검증, TabPFN-3.5 추가)과 노트북 05(평가군 2,000명 1회 평가, 추적군 종단 검증) 결과를 정리한다. 평가군은 9/28에 한 번 사용했으며, 이후 모델과 기준은 바꾸지 않는다.

## 1. 확정된 주 모델 (개발군 교차검증, 사전 규칙)

M0 CatBoost, M1 Elastic-net, M2 CatBoost, G CatBoost, M1+G Elastic-net, M2+G CatBoost, M1−Dx Elastic-net, M1−Dx+G TabPFN-3.5.

TabPFN-3.5는 모든 블록에서 AUPRC 최고치와 0.005 이내였고 보정 기울기가 0.88~1.01로 가장 좋았다. M1−Dx+G에서는 RF(0.2040)와 0.01 이내(0.2028)이고 더 단순한 모델이라 규칙에 따라 주 모델이 RF에서 TabPFN으로 바뀌었다(두 모델 차이 유의하지 않음).

## 4. 종단 검증 (추적기반 1,000명, 4차추적 698명, 4차 위축 양성 47명)

| M0, M2 기저 점수의 4차 위축 AUROC | 0.581 (0.509, 0.649), 0.556 (0.480, 0.625) |

| 기저 양성군의 4차 양성률 | 44.4% (40/90) |

M1 점수는 추적군에서도 기저 시점 위축을 판별한다(추적기반 1,000명 AUROC 0.607, M2 0.625). 즉 모델은 추적 코호트로 옮겨도 작동한다. 그러나 추적 자료에서는 고혈압, 당뇨군의 해마 원체적 감소가 오히려 느리다(연간 −0.2% 대 −0.7%, 기저 체적, 연령, 성별 보정 후에도 고혈압 +0.39, 당뇨 +0.38 %/년). 이는 9/22에 확인한 합성 추적 자료의 생성 구조(평균 회귀)와 같은 현상이며, 이 때문에 질환 기반 점수의 10.8년 예후 신호가 사라지고 가속 위축과 변화율 분석에서는 방향이 뒤집힌다. 생물학적 해석을 하지 않고 한계로 보고한다.

탈락자(302명)는 고령, 고혈압과 당뇨가 많고 M1 점수가 높았으나, 관측확률 가중 AUROC(0.542)는 비가중(0.549)과 비슷했다.

## 6. 보고서용 핵심 메시지

1. 문진과 진료 기록 수준의 임상 정보만으로 MRI 배정 효율이 무작위의 약 1.8배가 된다(20% 배정 시 위축자 36% 발견, 1명 발견당 MRI 3.6건 대 6.5건). 개발군과 평가군 성능이 같고 보정도 양호하다.
2. 혈액검사와 유전체는 진단 정보가 있으면 추가 가치가 없다(개발군, 평가군 모두 일관).
3. 진단 정보가 없을 때 유전체는 개발군에서 진단력 가치의 약 30~40%를 메웠고, 평가군에서도 같은 방향(1명 발견당 MRI 5.41 → 4.76건)이지만 주 검정은 유의하지 않아 탐색적 근거로 제시한다.
4. 위축 상태는 10.8년간 강하게 유지되어(r = 0.83, 기저 양성의 44% 대 음성의 1.2%) 한 번의 선별로 찾아낸 위축자가 장기 고위험군임을 뒷받침한다. 반면 임상 점수의 장기 예후 예측은 합성 추적 자료의 구조 때문에 확인되지 않았다.
5. 한계: 합성 자료, 평가군 검정력, 추적 자료의 생성 구조, TabPFN-3.5는 연구 및 평가용 라이선스(상용화 시 별도 라이선스 필요).
