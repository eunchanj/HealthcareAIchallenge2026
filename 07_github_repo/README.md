# 임상 및 유전체 데이터 기반 뇌 위축 바이오마커 예측과 MRI 검사 대상 선별

Healthcare AI Challenge 2026 (국립보건연구원, 한국생명정보학회 공동주관) 출품작의 분석 코드와 집계 결과. 접수번호 HAI-0024.

MRI 없이 얻을 수 있는 검진 문진 수준 임상 변수와 유전체 정보(APOE, 희소 PRS)로 해마 위축(연령과 성별 기대치 대비 z ≤ −1)을 예측하고, 그 점수를 MRI 검사 대상 선별의 우선순위로 쓰는 방안을 검증한다. 표형 데이터 모델 6종(Elastic-net, Random Forest, LightGBM, XGBoost, CatBoost, TabPFN-3.5)을 같은 분할과 같은 튜닝 예산의 중첩 교차검증으로 비교하고, 독립 평가군 2,000명에서 한 번 평가했으며, 추적 코호트에서 10.8년 뒤 위축 상태를 검증했다. 유전체 분석(PRS 연관, 변이 스캔, 매개분석, 멘델리안 무작위화)으로 유전 위험이 뇌에 닿는 경로를 설명한다.

## 이 저장소에 없는 것

대회 제공 합성자료(임상, 뇌영상 체적, 유전체)와 그로부터 만든 **개인 수준 파생 자료는 포함하지 않는다**(데이터 활용 서약). `oof_predictions.csv`, `base_analysis.csv`, `lead_dosage.csv`, 최종 모델 pickle 등 개인 단위 행이 있는 파일은 `.gitignore`로 막아 두었다. 산출물의 외부 공개도 서약으로 제한되므로 이 저장소는 **비공개(private)** 로만 운영한다.

## 재현

1. `pip install -r requirements.txt`. TabPFN-3.5는 ux.priorlabs.ai에서 라이선스 동의 후 API 키를 `code/.tabpfn_token`에 저장(저장소에 올리지 않음).
2. 대회 자료를 `02_Data/`에 두고 노트북을 01 → 02 → 04 → 03 → 05 → 06 → 07 순서로 실행한다. 자세한 입력과 출력, 스위치, 소요 시간은 `docs/코드북.md`.
3. 시드는 20260915로 고정. 노트북 05의 평가군 평가(`DRY_RUN = False`)는 한 번만 실행하는 설계다.

## 핵심 결과 (평가군 2,000명)

문진 수준 정보(M1, Elastic-net)만으로 AUROC 0.631, MRI를 점수 상위 20%에 배정하면 위축자 발견률 36%(무작위 20%), 1명 발견당 MRI 3.6건(무작위 6.5건). 혈액검사와 유전체는 진단 정보가 있으면 추가 가치가 없고, 진단 정보가 없을 때 유전체가 진단 가치의 약 40%를 메운다. 위축 표현형은 10.8년간 유지된다(r = 0.83). 유전 위험은 대사질환 진단을 거쳐서만 뇌에 닿는다(매개 비율 98%). 자세한 내용은 `share/` 노트북과 `docs/결과보고_초안.md`.
